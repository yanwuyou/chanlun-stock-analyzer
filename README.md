# 《缠论》股析 · 量化分析工具

> 基于缠中说禅《教你炒股票108课》完整理论体系的量化分析工具
> **4935 行代码 · 82 个函数 · 108 课全部可算法化内容**

一个不懂编程的人，用 AI 把晦涩的缠论拆成了一条能运行、能复现的规则链。

**`chanlun-stock-analyzer.skill`** — 可以直接安装到 Claude Code 使用。不需要理解代码，安装后对 AI 说"分析这只股票"即可。

## 为什么做这个工具

缠论难的不是概念多，而是概念之间层层嵌套。分型、笔、线段、中枢、走势类型、背驰、买卖点——单独讲解每个词不难，一放到真实 K 线图上就全是判断细节。

以前学这种东西，容易卡在两种状态：
- "文字好像看懂了，一上图就乱"
- "凭感觉能看出点东西，但说不清为什么"

所以这次换了一个办法：**把它写成程序**。

程序很诚实。你说这是顶分型，就得有判断条件。你说这里形成中枢，就要算出重叠区间。只要开始写代码，那些原来模糊的地方就会被迫变清楚。

## 分析管线

```
K线数据 → 包含关系处理 → 分型识别 → 笔的划分 → 线段划分
→ 中枢识别 → 走势类型判断 → 背驰判断(6条件) → 三类买卖点
→ 防狼术 → 表里关系 → 中枢监视器 → 中阴阶段 → 区间套
→ 同级别分解 → 机械化信号链 → 底部构造 → 综合决策
```

## 使用方式

> **三种方式，按需选择：**

### 方式一：Claude Code Skill（推荐，零门槛）
不需要懂 Python，不需要装环境。把 `chanlun-stock-analyzer.skill` 装进 Claude Code，直接说话就能用。

**安装步骤：**
1. 点击仓库里的 `chanlun-stock-analyzer.skill` 文件
2. 点击右上角 **Download**（下载图标）
3. 将文件放入 Claude Code 的 skills 目录
4. 对 Claude Code 说："分析 601689 拓普集团"

### 方式二：Python 源码运行
**安装步骤：**
1. 点击仓库右上角绿色 **Code** 按钮 → **Download ZIP**，解压
2. 安装 Python 3.8+ 和依赖：`pip install baostock mplfinance`
3. 在项目目录打开终端，运行下方命令

**单只股票分析：**
```bash
python chan_analyzer.py 601689 拓普集团
```

**多级别联立（30分钟+日线+周线+月线）：**
```bash
python chan_analyzer.py --full 601689 拓普集团
```

**批量扫描自选池：**
```bash
python chan_analyzer.py --watchlist
```

### Claude Code Skill（推荐，无需编程）
将 `chanlun-stock-analyzer.skill` 安装到 Claude Code，直接对 AI 说"分析 601689 拓普集团"即可。

已打包为 Windows EXE（约 86MB），无需安装 Python 环境，双击即可使用。获取方式见公众号「焱无忧AI手记」。
